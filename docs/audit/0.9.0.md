# Audit ids in the CHANGELOG

CHANGELOG entries end with ids in parentheses, such as `(FIN-77)` or
`(DJ-24, N-05)`. Each names a finding of a review made before that release:
the review found it, the entry fixed it, in whole or in part. The reviews
themselves are not published. This page gives every id the CHANGELOG cites,
from 0.7.0 on, a title and a status, so an entry can be traced to what it
answers.

The page describes no attack. A security finding that is still open is
listed by its id and severity only; it is described here, and in a GitHub
security advisory where it needs one, once a release fixes it. Statuses
are as of 0.11.0.

## The 0.9.0 audit

A whole-framework audit of 0.9.0, in ten areas, before 0.9.1. 0.9.1 fixed
its correctness and security findings that fit a patch release; 0.9.2 takes
its performance, infrastructure, documentation, and design hygiene; 0.10
the structural work. "Addressed in 0.9.2" means the 0.9.2 CHANGELOG has an
entry for it; that entry says how far it goes.

#### TEST-07: what the 0.12.0 weekly run left

The run of 2026-10-29 on `main` (0.12.0, CI run 40846333116), less the
functions 0.12.1-A and 0.12.1-B own and those 0.12 changed, and less what
0.13 killed. A mutant is counted as left: it may be equivalent, reach only
a server's code (the shards run on SQLite), or point at a missing test.

- **Killed in 0.13** (142): MFA's factor and throttle names, a project
  user table's refusal and default, and the grant keys a request's user
  is built with (18 of auth-4's, run here); the names
  refusals are held back under and a one-byte body limit
  (`http.middleware`); a webhook body's bytes, its task's options, and an
  erasure's marks (`webhooks.delivery`); how server loggers are routed,
  and what an own logger class is given (`log`); a prune's ledger key and
  value (`audit.seals`); each refused checkpoint's message and a
  checkpoint's exact text (`audit.checkpoints`); a principal read
  ahead's counts (`auth.principals`); and, once the stats run saw every
  test behind a cache, 27 of `auth.repositories._grants`'.
